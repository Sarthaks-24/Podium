You are given $t$ pairs of integers. For each pair $a$, $b$, print $a + b$.

## Input

The first line holds $t$, the number of pairs. Each of the next $t$ lines holds two integers $a$ and $b$.

## Output

Print $t$ lines: the sum of each pair, in the order given.

## Constraints

- $1 \le t \le 1000$
- Subtask 1 (40 points): $|a|, |b| \le 1000$
- Subtask 2 (60 points): $|a|, |b| \le 10^{18}$

The sum can exceed the range of a 32-bit integer.
