## Function problems

Use a function problem only when the description asks for one: the student writes a function and the platform reads the input and prints the result.

- Each language has one locked top and one locked bottom. The student edits only the part between them.
- The locked top holds every import. The student never needs to add one.
- In Java the locked bottom reads the input with Scanner.
- State the exact parameter types and the return type of the function for every language.
- Say whether a collection is an array or a list: an array or an ArrayList in Java, an array or a vector in C++, a list in Python.
